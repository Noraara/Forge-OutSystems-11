# Design specification
Project / surface / mode / decision status:
## Existing authority and references
What to preserve or intentionally redesign; sources and their applicable lessons.
## Shared rules
Semantic spacing scale, card insets, type hierarchy, colors/contrast, control sizes, focus, icon treatment and component contracts.
## Layout and navigation
Content widths, grouping, dividers, header alignment, recognizable links, parent destinations and unsaved changes.
## Responsive and content behavior
Desktop/phone/intermediate widths, long labels, dense data, wrapping, overflow and mobile input.
## States and interactions
Loading, empty, populated, submitting, validation, denied access, failure and success; motion purpose and reduced-motion behavior.
## O11 implementation
Native patterns, shared blocks, theme classes, justified extensions and affected screens.
## Rendered evidence
Viewport/state/build, observed measurements, screenshots and remaining issues. Approval belongs to a specific reviewed result.
